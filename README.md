# Brainpower Education

Static V1 prototype of the Brainpower Education student platform.

## Run locally

Because this project uses only HTML/CSS/JavaScript, you can open `index.html` directly. For the best PDF-preview behaviour, run a tiny local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

The project is suitable for GitHub Pages, Cloudflare Pages or Vercel. No AI API or backend is required.
