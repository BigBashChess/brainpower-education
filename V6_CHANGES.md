### Specialist 3/4

- a dedicated checkpoint for every major topic

## Mastery system

- Lesson completion now requires **all built-in lesson questions solved correctly**.
- The UI states a **100% lesson mastery** standard.
- Checkpoints display a **90%+ standard** and use Advanced/Separator material.
- Next-lesson links remain locked from the lesson end screen until the current lesson is mastered.
- Course map access remains open so strong students can still jump to a different topic deliberately.

## Course diagnostics

Every course now has a `#diagnostic/<course-id>` route that selects a representative question from each topic and shows diagnostic coverage from saved progress.
