# Brainpower Education — Legacy changelog (V4–V8)

The old root-level release notes are consolidated here ahead of the 1.x versioning system.

## V8 — Assessment Library Update
Expanded the Test Centre to the current Brainpower collection: Methods 1/2 and 3/4, Specialist 1/2, Physics Motion and Partial Fraction Bee. Added solution links where available, Physics/Other filtering, corrected split Kinematics/Proof PDFs, branded thumbnails, and safer handling of incomplete metadata.

## V7 — Deep Lesson Experience
Rebuilt lessons around learning goals, big picture, conceptual reasoning, core relations, worked methods/examples, exam traps, guided and optional practice, retrieval checks and mastery gates. Added `lesson-depth-v7.js`, with especially deep Specialist 3/4 treatment. Retained 98 lessons/checkpoints, 255 practice questions, diagnostics, Admin Studio, Test Centre, Vault, Progress, Tools and Arcade.

## V6 — Course Expansion
Expanded to 98 lessons/checkpoints and 255 practice-bank questions across Methods 1/2, Methods 3/4, Specialist 1/2 and Specialist 3/4. Added course diagnostics, stronger mastery rules, extensive Specialist 3/4 coverage, and the Number & Proof assessment. Retained static GitHub Pages deployment and local progress compatibility.

## V5 — Question Bank + Admin Studio
Expanded to 107 pre-built questions plus 14 daily challenges, introduced the maths answer pad with KaTeX/Math.js support, added the hidden static Admin Studio and publish-pack workflow, and made Brainpower Bird substantially easier in Chill mode.

## V4 — Precision Quality Pass
Improved Learn, Lessons, Practice, Tests, Exam Mode, Vault and Progress without changing the static architecture. Added clearer course command centres, topic readiness states, practice modes, test history, reading/writing exam phases, resource sorting and next-action progress guidance.

Git history retains the complete original release-note files if exact historical wording is ever needed.
