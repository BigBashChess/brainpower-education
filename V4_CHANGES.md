# Brainpower Education V4 — Precision Quality Pass

This release deliberately focuses on depth rather than adding more surface-area features.

## Learn
- Learning snapshot with lessons, questions, XP, streak and test attempts.
- A clearer four-stage study flow: Learn → Practise → Test → Review.
- Course command centre with mastery, available content, question-bank size and assessment count.
- Topic rows now distinguish learning-ready, practice-ready and planned content.
- Topic-level practice links and clearer lesson availability.

## Lessons
- Four-stage lesson structure with visible progression.
- Lesson position within the course.
- Practice completion status inside each lesson.
- Direct links to more topic practice and related assessments.
- Previous/next lesson navigation.

## Practice
- Practice modes: Full bank, Quick 5, Revisit misses and Separator only.
- Solved, attempted, unresolved and total-attempt statistics.
- Course/topic/difficulty/search filtering retained.
- Topic deep links now work from course and lesson pages.
- Shuffle and reset controls.
- Question cards show solved/attempted status.

## Tests
- Featured assessment area.
- Better test filtering including technology conditions.
- Previous best score appears on test cards and detail pages.
- Individual test pages now include suggested workflow and related learning.
- Exam Mode now has a proper pre-test setup screen, separate reading/writing phases, pause, skip-reading and finish flow.
- Marking scheme stays behind the finish step in Exam Mode.

## The Vault
- Resource type chips.
- Result count and sorting.
- Improved filtering behaviour while preserving bookmarks.

## Progress
- Next-best-action card.
- Review signal based on attempted-but-unsolved practice.
- Richer course mastery rows with solved and unresolved counts.

## Technical
- Still static and GitHub Pages compatible.
- No AI, server or database required.
- Existing V3 local progress remains compatible because the storage key is unchanged.
