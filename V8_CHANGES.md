## Test Centre improvements
- Tests without a marking scheme no longer show a broken marking-scheme button.
- Physics and Other assessments can be selected from the Test Centre course filter even though they are not full interactive courses yet.
- Tests whose total marks/questions are not reliably printed as a single metadata value display “See paper” rather than inventing a number.
- Corrected split question/solution PDFs are used for Kinematics and Number & Proof.
- Added branded subject thumbnails for the larger library.

- Existing Admin Studio published content is retained; the Number & Proof entry now points to the corrected split test and solution files.
